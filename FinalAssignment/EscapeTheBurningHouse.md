# Escape the Burning House

## About the Project

Escape the Burning House is a small point-and-click game that I created with Python and Pygame for my Tech Basics 1 final project.

The player is inside a burning house and has to find a way to escape. There are different objects in the room that the player can pick up and use. Some of them are useful for escaping and others are not.

The goal of the game is to find the right objects and use them correctly to get out of the house.

## How to Play

You can click on different objects in the room and pick them up. The inventory has limited space, so you have to decide which items you want to keep.

Not every item helps you. For example, there are different keys, but only one of them opens the door.

The game is mainly controlled with the mouse.

## How to Run the Game

You need Python and Pygame to run the game.

If Pygame is not installed, you can install it with:

```bash
pip install pygame
```

Then open the project and run the main Python file.

```bash
python main.py
```

All images should stay in the project folder because they are needed for the game.

## Main Features

* point-and-click interactions
* different objects that can be collected
* an inventory with limited space
* useful and useless objects
* different keys
* a locked door
* different game states
* a win and lose screen

## Why I Chose This Project

For my final project I wanted to create a game because I thought it would be a good way to use different things we learned during the semester in one project.

I also wanted to do something visual instead of making a game that only uses text. That is why I decided to use Pygame and create a room where the player can click on the objects directly.

I chose an escape game because it gave me the possibility to work with different items, conditions and interactions.

## What I Learned

During the project I learned more about how Pygame works and how to connect different parts of a program.

I worked with functions, lists, if statements, variables and events. I also learned how to load images and place them in a Pygame window.

One part that was sometimes difficult was making sure that the objects and the inventory worked together correctly. I also had to think about what should happen when the player uses the wrong or right object.

The project helped me understand better how the Python basics we learned during the semester can be used for a bigger program.

## Possible Improvements

There are still some things I could add to the game in the future. For example, I could add more rooms, more objects, sounds or different ways to escape.
